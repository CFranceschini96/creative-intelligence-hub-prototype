# Creative Intelligence & Innovation Hub — Prototype
*Built in Lovable*

## The problem
I needed to communicate a structural vision for a global internal knowledge hub to senior leadership — what it would contain, how it would be navigated, and what the user experience would feel like — before committing to building it in SharePoint. A slide deck wouldn't make it tangible enough. A written spec would be ignored.

## What I built
A working front-end prototype of the hub built in Lovable, covering:

- **Home page** — featured resources, recent additions, community announcements
- **Resource library** — filterable by market, tool type, and use case
- **Tool directory** — overview of active and pipeline tools with status indicators
- **Community section** — webinar schedule, newsletter archive, Champions Network directory

The prototype was built in a single session and used as a reference in a leadership presentation to align on structure and priorities before the production build began.

## Outcome
The prototype was used as the structural brief for the SharePoint build. Several navigation decisions and content categories came directly from feedback on the prototype rather than going back and forth on a written spec.

## Tools used
- Lovable (AI-powered front-end builder)

## What I learned
A working prototype — even a rough one — changes the quality of the conversation with stakeholders. People give much more useful feedback on something they can click through than something they have to imagine. Building the prototype first saved time overall even though it added a step.
